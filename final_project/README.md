GigaVibe AI Assistant

Консольное приложение для взаимодействия с большими языковыми моделями (LLM). Ассистент поддерживает потоковый вывод (streaming), управление контекстом диалога и инъекцию локальных файлов в запросы пользователя.

Под капотом: YandexGPT и OpenAI API

Проект настроен на работу с экосистемой Yandex Cloud (YandexGPT), но использует библиотеку openai в качестве клиента

Интерфейс связи: Запросы отправляются через стандартный клиент openai. Это позволяет использовать приложение с любой совместимой нейросетью при изменении api_host.

Специфика Yandex: Для работы с YandexGPT используется URI-формат указания модели gpt://<FOLDER_ID>/yandexgpt-lite/latest. Помимо API-ключа для маршрутизации запросов необходим идентификатор каталога (folder_id).

Streaming Response: Ответы выводятся в консоль токенами (словами) в режиме реального времени по мере их поступления от серверов, не блокируя приложение в ожидании полной генерации текста.

Ключевые возможности

Скользящее окно контекста: Приложение сохраняет историю диалога. Во избежание переполнения памяти нейросети самые старые сообщения автоматически удаляются при достижении установленного лимита сообщений или символов. Системный промпт сохраняется всегда.

Чтение локальных файлов: Пользователь может встроить содержимое любого текстового файла (до 5 МБ) в запрос с помощью синтаксиса @::путь/к/файлу::.

Почанковая обработка (/filechunk): Интерактивный режим для обработки объемных текстов. Файл разбивается на абзацы или блоки символов и отправляется нейросети по частям.

Обработка прерываний: Приложение корректно обрабатывает KeyboardInterrupt (Ctrl+C) для отмены текущей генерации ответа без полного завершения работы программы.

Установка и настройка

Зависимости
Убедитесь, что у вас установлен Python 3.10+, и выполните установку необходимых пакетов:

pip install -r requirements.txt

Конфигурация
В корневой папке проекта создайте файл config.yaml. Данный файл содержит секретные ключи и должен быть добавлен в .gitignore.

Пример config.yaml:

api_key: "ВАШ_СЕКРЕТНЫЙ_КЛЮЧ"
api_host: "https://llm.api.cloud.yandex.net/v1"
folder_id: "ВАШ_FOLDER_ID"
limit_message: 20
limit_chars: 4000
temperature: 0.7
system_prompt: "Ты ИИ-ассистент, помогающий разработчику. Отвечай кратко и по делу."

Настройки также можно задать через переменные окружения ОС (они имеют более высокий приоритет).

Использование

Для запуска чат-бота выполните команду:

python main.py

Доступные команды в чате:

/reset — полная очистка истории текущего диалога и консоли.

\q — завершение работы приложения.

/filechunk — запуск режима почанкового чтения файла. Пример авто-запуска: /filechunk paragraph=2 -y (разбиение по 2 абзаца с непрерывной обработкой).

Инъекция файлов:
Укажите путь к файлу в двойных двоеточиях внутри запроса:

Найди ошибку в этом коде: @::src/main.py::

Тестирование

Проект покрыт unit-тестами. Для запуска тестов и генерации HTML-отчета о покрытии (в директорию htmlcov/) используйте команду:

pytest test_app.py --cov=. --cov-report=html
